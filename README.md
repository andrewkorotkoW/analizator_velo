# anal_velo

Анализатор велотренировок: пользователь загружает CSV с данными своих поездок,
система строит динамический график прогресса (дистанция и средняя скорость по
датам) и даёт текстовую рекомендацию на основе сравнения последних тренировок
с предыдущими.

## Формат входных данных

CSV с заголовком и колонками:

| Колонка         | Обязательна | Описание                              |
|-----------------|-------------|----------------------------------------|
| `date`          | да          | дата тренировки, `YYYY-MM-DD`          |
| `distance_km`   | да          | дистанция, км                          |
| `duration_min`  | да          | длительность, мин                      |
| `avg_speed_kmh` | нет         | средняя скорость, км/ч                 |
| `avg_hr`        | нет         | средний пульс, уд/мин                  |

Файл должен быть в кодировке UTF-8. Пример — [`tests/fixtures/sample_workouts.csv`](tests/fixtures/sample_workouts.csv).

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app
```

Сервер поднимется на `http://localhost:5000/` (Flask в режиме `debug=True`).

## Пользовательский сценарий

1. Открыть `http://localhost:5000/` — откроется дашборд тренировок.
2. Ввести email в поле «Email».
3. Выбрать CSV-файл с тренировками и нажать «Загрузить».
4. На странице появится график прогресса (дистанция и средняя скорость по
   датам) и текстовая рекомендация под ним.

Под капотом форма обращается к трём эндпоинтам:

- `POST /api/workouts/upload` — принимает `user_email` и файл `file` (CSV),
  парсит и сохраняет тренировки в SQLite (`data.db` в корне проекта, путь
  можно переопределить переменной окружения `ANAL_VELO_DB_PATH`).
- `GET /api/workouts?user_email=...` — возвращает сохранённые тренировки
  пользователя, отсортированные по дате.
- `GET /api/recommendations?user_email=...` — возвращает рекомендацию:
  для расчёта требуется минимум 4 тренировки; последние сравниваются с
  предыдущими по средней дистанции (и по средней скорости, если она указана).

## Тесты

```bash
pytest
```

Тесты покрывают парсер CSV, хранилище (SQLite), API-эндпоинты, генерацию
рекомендаций и рендер страницы дашборда.
